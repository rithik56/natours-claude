  <files>src/components/ui/link.tsx, src/components/ui/link.module.css, src/components/ui/text-field.tsx, src/components/ui/text-field.module.css, src/app/styleguide/sections/link-section.tsx, src/app/styleguide/sections/text-field-section.tsx</files>
  <read_first>docs/design/copy.md "Field-validation wording" table (exact error strings: "Password must be 8 to 72 characters.", "{Field name} is required.", "Enter a valid email address.")</read_first>
  <behavior>
    - `Link` with an `href` starting with `/` or no protocol renders `next/link`'s `<Link>`; an `href` starting with `http(s)://` renders a plain `<a target="_blank" rel="noopener noreferrer">` (external links always open in a new tab with `rel` set — mitigates reverse-tabnabbing, needed later for photo-credit outbound links).
    - `TextField` with no `errorMessage` renders a plain labelled input with no `aria-invalid`/`aria-describedby`. With an `errorMessage`, it renders `aria-invalid="true"`, `aria-describedby` pointing at a generated `id` on the error text, and the error text visible in the UI next to the field (U16).
  </behavior>
  <action>
Build `ui/link.tsx`: typed props extending anchor attributes plus `href: string`; internal/external branching exactly as the behavior block states; `link.module.css` styles both branches identically (colour, underline, `:focus-visible` using the page-local focus token — default `--color-focus`, not the accent variant, since links mostly sit on light surfaces). Build `ui/text-field.tsx`: props `{ label: string; name: string; errorMessage?: string } & ComponentPropsWithoutRef<'input'>`; generates `id={name}` and (when `errorMessage` is set) `errorId={`${name}-error`}`; renders a `<label htmlFor={name}>`, the `<input>` with `aria-invalid`/`aria-describedby` wired per the behavior block, and a `<p id={errorId} role="alert">{errorMessage}</p>` only when present (matching copy.md's exact wording is the *caller's* job — this component renders whatever string it's given verbatim, never invents wording). `text-field.module.css`: default/focus/error states, error text in `--color-error`, `@layer components`. Add both styleguide sections showing: default, filled, focused (document via `:focus` note), disabled, and error (using one of copy.md's exact field-validation strings as the example, e.g. "Enter a valid email address.").
  </action>

  </verify>
  <done>Both components render with typed props; `TextField`'s error state links the message to the input via `aria-describedby`; `Link` opens external hrefs safely with `rel="noopener noreferrer"`.</done>
