<decisions>
- **`closedby` for the confirm dialog (RESEARCH.md Open Question 2):** do not set `closedby="any"` — leave the default (Esc and the explicit Cancel/Deactivate buttons only). An accidental backdrop click doing nothing is harmless; the destructive action is never one accidental click away. **Reversibility: reversible** — `closedby="any"` can be added later with no markup change.
- **MapFrame is a static placeholder (ADR 0028):** this phase builds only the frame/SVG-route-line signature element Phase 2's mockup already proved out; the real Leaflet map (`RouteMap`) is Phase 4. `map-frame.tsx` accepts the same `locations`-shaped prop the mockup's inline SVG used, so Phase 4 can later decide whether `RouteMap` wraps or replaces it without changing the prop contract.
</decisions>
