| Boundary | Description |
|----------|-------------|
| Server-thrown error → `error.tsx` props | Next.js redacts `error.message` for Server Component errors in production, but `error.tsx`'s own code must not work around that redaction (RESEARCH.md Pitfall 3). |
| Root layout throw → `global-error.tsx` | The one path with no shell/CSS available — must degrade safely even if `tokens.css` failed to load. |
