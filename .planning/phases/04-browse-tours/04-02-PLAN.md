## Phase Goal

ROADMAP Phase 4 goal, quoted verbatim (not in user-story form; no story is invented): A traveller can find a tour that fits their fitness, dates and budget, and see its route, itinerary, guides, reviews and photo credits. API clients get the same catalogue.

<objective>
D-11's first build slice: `npm run seed` loads the real catalogue and uploads its photos through the storage adapter, and the app serves those photos from its own origin. This adds a disk-backed storage adapter for development and ci plus a `/media/[...key]` Route Handler (the in-memory fake cannot be shared between the seed process and the web server, RESEARCH Pitfall 2), then the full idempotent load with `--reset`, the environment guards and the password keys.

Purpose: every later Phase 4 page reads seeded tours and shows seeded photos. Date rolling, the README rule checks and the CI wiring follow in plan 04-03.
Output: `scripts/seed.ts` and `scripts/seed/{load,run}.ts`, `local-disk-storage.ts`, `/media`, ADR 0029.
</objective>

<decisions>
- **Disk adapter in development and ci, fake in test, S3 in Phase 8 (ARC-15 option A, DEL-16).** `urlFor(key)` returns the root-relative `/media/<key>` in every adapter. Reversibility: costly — the `Storage` interface shape (`get`, root-relative `urlFor`) is a cross-module contract later phases build on, but it sits behind the adapter seam, so Phase 8's S3 adapter implements the same interface.
- **`images.localPatterns` instead of D2's `remotePatterns`.** Photos are same-origin, so the optimiser never makes a network request and no host is added to the CSP. Recorded in ADR 0029. Reversibility: reversible.
- **Seed environment guard is an APP_ENV allowlist (research Open Question 5, settled by the orchestrator).** No database-name allowlist. Reversibility: reversible.
- **Tour `createdAt` is a fixed instant per position in tours.json** (2026-10-01T09:00:00+05:30 plus the index in minutes), so a re-run on another day changes nothing and the API's `-createdAt` default order is stable. Reversibility: reversible.
</decisions>

- RESEARCH A1: `tsx` may not forward Node's env-file flags, so `scripts/seed.ts` loads `.env.local` itself with `process.loadEnvFile` inside a try (a missing file is fine). Values already in the environment win.
</assumptions>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `/media/[...key]` | A visitor-chosen path selects a file on the server's disk |
| Seed CLI → MongoDB | A developer-run script with write access to every collection |
| Next image optimiser → image source | The optimiser fetches the source named in the `url` query |
