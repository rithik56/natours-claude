## Phase Goal

ROADMAP Phase 4 goal, quoted verbatim (not in user-story form; no story is invented): A traveller can find a tour that fits their fitness, dates and budget, and see its route, itinerary, guides, reviews and photo credits. API clients get the same catalogue.

<objective>
The route map (R8, D-07, ADR 0028): a lazily loaded, non-interactive Leaflet map that replaces the static route inside the same slot when it scrolls into view, draws the route once, and outlines India from the Survey of India boundary on our own origin, with the itinerary always visible. MapFrame moves onto the token scale (C4, C6) and shares one projection with Leaflet, and a `vendor` cascade layer keeps Leaflet's CSS below the components. The plan ends with the user choosing the boundary simplification by eye.

Purpose: the route is the product's signature element; it must look the same before and after Leaflet arrives, show India's official boundary, and cost nothing on pages that have no map.
Output: `route-projection.ts`, `RouteMapSlot`, `route-map.tsx`, the boundary file, ADRs 0034 and 0035.
</objective>

<decisions>
- **`L.CRS.Simple` with the shared projection** instead of Web Mercator, so the Leaflet route has the same shape as the static drawing (RESEARCH Pitfall 14). Reversibility: reversible.
- **Leaflet mounts over the static drawing and the static drawing is removed only once Leaflet and the boundary are ready**; any failure unmounts Leaflet and leaves the static route. Reversibility: reversible.
- **Boundary file at `public/data/india-soi.geojson`** (ADR 0028 suggested `src/data/`; a static file is served from our origin without bundling). Prettier ignores `public/data/`. Recorded in ADR 0034. Reversibility: reversible.
- **Attribution control gets its token styles through a module class added to its container** (`getContainer().classList.add(...)`), keeping single-class selectors in the CSS module. Reversibility: reversible.
- **Leaflet 1.9.4** (2.0 is not stable). Reversibility: costly (a dependency major bump later), behind one client component.
</decisions>

<assumptions>
- RESEARCH A5: setting `pathLength="1"` on Leaflet's SVG path elements and reusing the CSS dash draw works; if it does not, the executor measures `getTotalLength()` in the effect and sets the dash values from it (same visible result, still CSS-animated).
- `window.L` is defined once Leaflet's module has run (Leaflet 1.9 assigns its global); the Playwright spec also checks for `.leaflet-container`, so the test does not depend on the global alone.
