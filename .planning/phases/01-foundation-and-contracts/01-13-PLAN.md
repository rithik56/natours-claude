  <action>
Install `npm install -D @lhci/cli@0.16.0`.

`scripts/measure-bundle.ts` (Node-native) exports `scriptTransferSize(lhr)`, `median(values)` and `checkBudget(measured, baseline)`. The CLI has two modes.
- `--record`: read the `.lighthouseci/lhr-*.json` reports whose requested URL path is `/`, take the median script transfer size, and write `docs/bundle-baseline.json` with `JSON.stringify(…, null, 2)` and a trailing newline. The fields are `floorBytes`, `budgetDeltaBytes` (40960), `route` (`/`), `measuredAt` (ISO date), `preset` (mobile), `lighthouse` (from the report's `lighthouseVersion`) and `next` (the installed version).
- `--check`: compare the median against floor plus delta, and exit 1 when it is over, or when the reports or the baseline are missing.

`lighthouserc.cjs`:
- `ci.collect`:
  - `url: ['http://localhost:3300/']`, `numberOfRuns: 3`;
  - `startServerCommand: 'node_modules/.bin/next start -p 3300'`, `startServerReadyPattern: 'Ready'`;
  - `settings.chromeFlags: '--no-sandbox --headless=new'` (A8), keeping Lighthouse's default mobile emulation.
- `ci.assert.assertMatrix`: when `docs/bundle-baseline.json` exists, one entry for the `/` URL pattern asserting `resource-summary:script:size` with `['error', { maxNumericValue: floorBytes + budgetDeltaBytes, aggregationMethod: 'median' }]`.
- No `upload` section: results stay local and in CI artifacts, never public temporary storage.

Add the scripts:
- `lhci:collect` (`lhci collect --config=lighthouserc.cjs`);
- `bundle:record` (`npm run lhci:collect && node scripts/measure-bundle.ts --record`);
- `bundle:check` (`npm run lhci:collect && lhci assert --config=lighthouserc.cjs && node scripts/measure-bundle.ts --check`).

Let ESLint treat `*.cjs` as CommonJS. Add `lighthouserc.cjs` to knip entries only if knip reports it.

Then record the baseline locally:
- `docker compose up -d --wait mongo`;
- `npm run build`;
- `APP_ENV=ci APP_URL=http://localhost:3300 MONGODB_URI=mongodb://127.0.0.1:27017/natours SESSION_SECRET=<openssl rand -base64 48> npm run bundle:record`.

Commit the resulting `docs/bundle-baseline.json`. RESEARCH A4: confirm the recorded floor is much smaller than the raw chunk sizes in `.next/static/chunks` (that is, gzip is in effect), and note both numbers in the SUMMARY.

Commit as `feat(perf): record the R9 JavaScript floor with Lighthouse CI [R9] (01-13)`, with a one-line reason for @lhci/cli.
