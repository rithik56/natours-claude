`src/server/modules/tours/model.ts` (server-only) follows plan.md §1.3's Tour table, without the discount field (D-05):
- `name`: required, unique, trimmed, 10 to 40 characters.
- `slug`: unique index.
- `duration`: required integer of at least 1, not unique.
- `maxGroupSize`: required integer of at least 1.
- `difficulty`: enum easy, medium or difficult.
- `ratingsAverage`: 1 to 5, default 4.5, with a setter rounding to one decimal.
- `ratingsQuantity`: integer of at least 0, default 0.
- `price`: required integer of at least 1 (whole rupees, B20).
- `summary`: required, trimmed. `description`: trimmed.
- `imageCover`: required. `images`: string array, at most 3.
- `photoCredits`: an array of `{ file, title, author, license, licenseUrl, sourceUrl }`, all required strings.
- `startDates`: Date array, each validated with `isIstMidnight` (B19).
- `startLocation`: GeoJSON Point `{ type: 'Point', coordinates: [lng, lat], address, description }`, with longitude −180 to 180 and latitude −90 to 90.
- `locations`: array of Point plus `description` and `day` (an integer of at least 1).
- `guides`: ObjectId refs to User.

Schema options `{ timestamps: true }`. Indexes exactly as §1.3. Slug hooks:
- pre('validate'): set `slug = slugify(name)` when the name is modified or the slug is empty;
- pre('findOneAndUpdate'): set the slug when the update changes the name.

No other hooks and no `pre(/^find/)`. Apply `withUpdateValidators`, and export `Tour = registerModel('Tour', schema)` and the types.

`src/server/modules/tours/dto.ts` exports:
- `TourSummary` and `toTourSummary`: `{ id, name, slug, duration, maxGroupSize, difficulty, price, ratingsAverage, ratingsQuantity, summary, imageCover, startDates: IstDay[], startLocation: { coordinates, address, description } }`;
- `TourDetail` and `toTourDetail`: the summary plus `description`, `images`, `locations` (`{ day, description, coordinates }` in document order), `guides: PublicUser[]` (it requires populated guides, and throws an Error if a guide is an id) and `photoCredits`.

Every array is copied in document order.

Add `createTour(options?: { slug?: string; overrides?: Partial<{ price; duration; maxGroupSize; difficulty; startDates: Date[]; ratingsAverage; ratingsQuantity }>; withGuides?: boolean })` to `test/helpers/factories.ts`:
- It copies the named seed tour (default: the next one not yet created), with its seed `_id`.
- It converts seed start dates with `fromIstDay`.
- With `withGuides`, it first creates the tour's seed guides through `createUser({ email })`, by looking up their seed ids, so populate works.
- Text fields can't be overridden.

Commit as `feat(tours): Tour model, slug and DTOs [B5, B19, B20, S3, R6] (01-08)`.
