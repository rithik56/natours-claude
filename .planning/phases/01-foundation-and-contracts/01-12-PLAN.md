`src/server/actions/action-state.ts` (server-only) exports:
- `type ActionState<T = void>`, verbatim from plan.md §4.3: `{ ok: true; data?: T; message?: string } | { ok: false; error: { code: ErrorCode; message: string; fieldErrors?: Record<string, string> } }`;
- `type ActionResult<T> = { data?: T; message?: string }`, the handler's return.

`src/server/actions/action.ts` (server-only) exports `action<S extends z.ZodType, T>(schema: S, handler: (input: z.infer<S>, ctx: { user: SelfUser | null; requestId: string; log: Logger }) => Promise<ActionResult<T> | void>, options: { access: Access; rateLimit?: { rule: RateLimitRule; key: (input: z.infer<S>) => string } })`. It returns `(prev: ActionState<T>, formData: FormData) => Promise<ActionState<T>>`, the `useActionState` shape (ARC-09).

The steps, in this order:
1. Take the request ID from `(await headers()).get('x-request-id')` when it is a UUID, otherwise mint one. Create `log = requestLogger(id)`.
2. `resolveAccess(options.access)`. Undefined access throws FORBIDDEN, which becomes an ActionState.
3. Turn the FormData into an object, dropping keys that start with `$ACTION`. Repeated keys become arrays; File values are kept. Then `schema.safeParse`. On failure return VALIDATION_ERROR with `messages.errors.VALIDATION_ERROR` and `issuesToFieldErrors`.
4. Rate limit through `getDeps().rateLimiter`.
5. Run the handler, and check that the returned `data` is plain data: primitives, arrays and objects whose prototype is Object.prototype or null, recursively. Otherwise throw an Error naming the offending path. A Date is not plain: DTOs use ISO strings.
6. Return `{ ok: true, ...result }`.

On a throw:
- `unstable_rethrow(err)` first (B18);
- `const appErr = toAppError(err)`;
- for INTERNAL, log with the error and rethrow the original, so it reaches error.tsx (B9);
- otherwise log a warning and return `{ ok: false, error: { code, message, fieldErrors } }`, with `fieldErrors` built from `details` when present.

Commit as `feat(actions): action() with default deny, field errors and redirect pass-through [B18, S1, B9, R6] (01-12)`.
